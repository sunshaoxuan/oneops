基本台帳 操作マニュアル

組織区分、組織機関、製品、版数、機能 Module を検索し、権限に応じて追加または編集する手順です。

この手順でできること業務で参照する基礎データの確認と保守
操作の流れ
  1. 権限を確認する
  2. 台帳を切り替える
  3. 組織区分を保守する
  4. 組織機関を保守する
  5. 製品を保守する
  6. 版数と Module を保守する
  7. 保存できないとき
01

入口と権限を確認する

操作必要権限画面での結果
基本台帳を開くcatalog.read左メニューに「基本台帳」が表示されます。
組織区分、製品、版数、Module を編集catalog.write追加 Button と編集 Icon が表示されます。
組織機関を表示catalog.read と organizations.read横メニューに「組織機関」が表示されます。
組織機関を追加、編集organizations.write組織機関の追加 Button と編集 Icon が表示されます。
台帳の参照方式通常画面では内部物理 ID を表示しません。他の業務データは、選択した台帳 Record の安定した物理 ID を保存します。Code と名称は検索及び業務表示に使用します。
02

対象の台帳へ切り替える

  1. 左メニューの「基本台帳」を押す

    画面上部に「組織区分」「組織機関」「製品・版数」の横メニューが権限に応じて表示されます。

  2. 保守する台帳名を押す

    初回は表示可能な台帳のうち、組織区分、組織機関、製品・版数の順で最初のものが開きます。

  3. 見出しと操作 Button を確認する

    参照権限だけの場合は一覧を確認できます。書込権限がある場合だけ追加と編集操作が表示されます。

共通組織 Context の影響基本台帳は System 共通データです。Header で選択中の組織機関による絞り込みは行いません。
03

組織区分を検索、追加、編集する

  1. 横メニューで「組織区分」を選ぶ

    一覧に Code、名称、操作が表示されます。列見出しで Code または名称を並べ替えられます。

  2. 検索欄へ Code または名称を入力する

    入力文字列を Code と名称へ部分一致で適用し、一覧を絞り込みます。

  3. 追加する場合は「組織区分を追加」を押す

    Modal で区分 Codeと区分名称を入力します。どちらも必須です。

  4. 編集する場合は対象行の編集 Icon を押す

    現在値が Modal へ設定されます。Code または名称を修正します。

  5. 保存して一覧を確認する

    成功すると Modal が閉じ、一覧 Query が更新されます。既存組織機関の区分参照は同じ物理 ID のまま維持されます。

削除操作はありません組織機関から参照中の台帳整合性を保つため、現在の画面では削除を提供していません。
04

組織機関を検索、追加、編集する

  1. 横メニューで「組織機関」を選ぶ

    組織区分、Code、名称、略称、保守状態、問合システム顧客 Code、備考が一覧に表示されます。

  2. 検索して対象を絞り込む

    検索欄は一覧の主要文字項目を対象にします。列見出しで並べ替え、Header 境界を Drag して列幅を調整できます。

  3. 追加または編集を開く

    新規は組織機関を追加、既存は行の編集 Icon を押します。

  4. 必須項目を入力する

    組織区分を候補から選び、機関 Codeと機関名称を入力します。

  5. 業務項目を確認する

    略称、保守状態、問合システム顧客 Code、備考を必要に応じて入力します。問合システム顧客 Code が未設定の場合、連携時は機関 Code が使用されます。

  6. 保存して一覧を確認する

    成功すると一覧が再取得されます。Code や名称を変更しても、この組織を参照する他データは物理 ID 参照を維持します。

入力項目

項目必須使われ方
組織区分必須登録済み組織区分の物理 ID を保存します。
機関 Code必須検索、表示、外部対応の業務識別子です。
機関名称必須共通 Context や製品構築の初期機関名に使います。
略称任意画面表示と問合サイト対応候補に使います。
保守状態必須現行の保守対象状態を示します。
問合システム顧客 Code任意UPDS 顧客との対応に使います。
備考任意台帳運用上の補足です。
05

製品を追加、選択、編集する

  1. 横メニューで「製品・版数」を選ぶ

    左側に製品一覧、右側に選択製品の情報、版数一覧、Module 一覧が表示されます。

  2. 製品一覧から対象を選ぶ

    選択行が Active になり、右側に Code、名称、略称と登録版数が表示されます。

  3. 新規製品は「製品を追加」を押す

    製品 Codeと製品名称は必須、略称は任意です。

  4. 既存製品は見出しの編集 Icon を押す

    現在値を修正して保存します。製品の物理 ID と既存版数の所属は維持されます。

06

版数と機能 Module を保守する

  1. 製品を選択し「版数を追加」を押す

    標準版数は必須、表示版数は任意です。保存後、版数一覧へ自然順で表示されます。

  2. 版数を選ぶ

    版数行には標準版数、表示版数、Module 件数が表示されます。選択すると右側の Module Table が切り替わります。

  3. 版数を編集する

    版数見出しの編集 Icon を押し、標準版数または表示版数を修正して保存します。

  4. 「機能モジュールを追加」を押す

    Module CodeとModule 名称は必須、略称は任意です。

  5. 既存 Module を編集する

    Module Table の行編集 Icon を押し、Code、名称、略称を修正します。同じ安定 Module が複数版数に存在する場合、共通情報へ反映されます。

版数の並び順数字 Segment を比較した自然昇順です。例として 2.9.2 は 2.11.1 より前、V7 は V10 より前に表示されます。
07

保存できないときの確認順

  • 追加 Button がない対象台帳の書込権限を確認します。参照権限だけでは操作を表示しません。
  • 組織機関 Tab がないorganizations.read の割当を確認します。
  • 必須エラーModal 内の赤い項目説明を確認し、Code、名称、区分または版数を入力します。
  • Code 重複一覧を検索し、既存 Record を編集するか異なる業務 Code を使用します。
  • 保存後に見つからない検索文字を消し、並べ替えを確認します。版数は自然順で表示されます。
  • 参照先への影響が心配Code と名称を変更しても物理 ID 参照は維持されます。業務表示への影響は関連画面で確認します。
