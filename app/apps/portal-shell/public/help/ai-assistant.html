AI アシスタント 操作マニュアル

会話を作成し、文章または添付を送信し、逐次表示される回答を確認する手順です。クイックアシスタント、問合せ参照、停止、履歴管理も説明します。

この手順でできること用途別の会話開始から回答の再利用まで
操作の流れ
  1. 利用前の確認
  2. 会話を始める
  3. 機能を選ぶ
  4. ファイルを添付する
  5. メッセージを送る
  6. 生成中の操作
  7. 履歴を管理する
  8. 問題が起きたとき
01

利用前の確認

画面入口
左メニュー「AI アシスタント」
必要権限
ai.assistant.use
履歴の保存先
OneOps Session / Task / Event Ledger
会話ごとに Model 設定を保持します新しい会話は作成時の Model と推理レベルを開始設定として保持します。各 Task も実行時の設定を Ledger へ保存します。

画面の主な領域

  • 左側または履歴 Drawer に新しい話題、購読済み機能、会話履歴が表示されます。
  • 中央に利用者メッセージ、添付、AI 回答、処理状況が時系列で表示されます。
  • 下部に添付操作、入力欄、送信または停止操作があります。
  • 問合支援から開いた場合は、会話上部に参照中の問合せが表示されます。
02

通常の新しい会話を始める

  1. 「新しい話題」を押す

    履歴領域の主ボタンを押すと、通常用途の新しい Session が作成され、自動的に選択されます。

  2. 空の会話画面を確認する

    中央に AI アシスタント名、開始案内、開始 Model、推理レベル、速度が表示されます。履歴には新しい会話が追加されます。

  3. 入力欄へ依頼を書く

    目的、対象、期待する形式、制約を一つの依頼として入力します。改行は Shift + Enter、送信は Enter です。

話題を分ける基準同じ資料や目的を続ける場合は同じ会話へ追加します。対象、権限範囲、成果物が変わる場合は「新しい話題」を作成します。
03

クイックアシスタントから会話を始める

  1. 「新しい話題」右側の Menu を開く

    クイックアシスタントの一覧が表示されます。名称と説明を確認して用途を選びます。

  2. 必要な機能を選択する

    選択した機能の物理 ID を持つ専用 Session が作成されます。入力欄にはその機能の開始 Prompt が案内として表示されます。

  3. 頻繁に使う機能を購読する

    一覧の星操作を押すと購読状態になります。購読済み機能は履歴領域の購読した機能へ表示され、次回から直接会話を作成できます。

  4. 購読を解除する

    塗りつぶされた星を再度押します。既存会話は削除されず、購読一覧からだけ外れます。

04

ファイルまたは画像を添付する

制限現在の値画面の動作
1 ファイル25 MiB まで超過時は警告し、追加しません。
1 回の件数10 件まで既存の待機添付を含めて判定します。
1 回の合計50 MiB まで超過するファイルは追加しません。
大きな貼り付け文字列32 KiB 超日時付き TXT 添付へ変換します。
  1. Clip 操作を押すか、ファイルを貼り付ける

    ファイル選択、Clipboard 貼り付け、Drag & Drop を利用できます。同じファイルは重複追加されません。

  2. Upload 状態を確認する

    画像は Thumbnail、その他はファイル名と Size で表示されます。Uploading 中は Loading Icon が出ます。

  3. 不要な添付を外す

    各添付の閉じる操作を押します。Upload 済みの場合は OneOps 側の未送信添付も削除されます。

  4. 画像を必要に応じて拡大する

    Thumbnail を押すと Preview Modal が開きます。送信前に対象画像を確認できます。

送信可能になる条件すべての添付が READY になるまで送信できません。Upload に失敗した項目は外し、必要なら再度追加します。
05

メッセージを送信して回答を確認する

  1. 依頼文を入力する

    入力欄は 1 行から最大 5 行まで自動拡張します。Enter で送信、Shift + Enter で改行します。

  2. 送信操作を押す

    文章または READY の添付がある場合に送信できます。添付だけの場合は「添付ファイルを解析してください。」が依頼文として補われます。

  3. 利用者メッセージを確認する

    送信内容と添付が会話末尾へ表示され、Task が QUEUED になります。問合せ参照中は現在の問合せ Context も Task へ保存されます。

  4. 処理状況を開く

    処理状況を押すと「依頼を受け付けました」「回答を準備しています」「回答を生成しています」の状態を確認できます。

  5. 逐次表示される回答を読む

    回答は受信済み本文から順に表示されます。完了すると最終本文が Ledger へ確定し、回答下部の Copy 操作を利用できます。

問合支援から開いた場合

会話上部のこの会話の問合せに Ticket No.、質問位置、参照状態が表示されます。対象を押すと問合支援へ戻り、その Ticket の詳細を開きます。現在参照中の問合せは次の送信に Context として含まれます。

06

回答生成中に操作する

  • QUEUEDOneOps が依頼を受け付け、実行開始を待っています。
  • RUNNINGModel への要求と回答準備を実行しています。
  • STREAMING受信した回答本文を会話へ逐次表示しています。
  • COMPLETED回答と Token 使用量を Task Ledger へ確定しました。
  • CANCELLED停止要求により生成を終了しました。受信済み本文がある場合は残ります。
  • FAILED接続、設定、契約または Model 応答に失敗しました。
  1. 次の依頼を入力して待機する

    生成中も入力欄へ Draft を書けます。送信と添付操作は現在 Task が終端になるまで Locked です。

  2. 「回答の生成を停止」を押す

    送信位置に表示される四角い停止操作です。停止中は Loading が表示されます。OneOps は Provider の残存 Event を確定回答として扱わず、Task を CANCELLED へ到達させます。

  3. 接続が切れた場合は再接続表示を確認する

    Browser は最後に受信した Sequence から再開します。重複 Event は表示しません。

同じ会話の重複実行未完了 Task がある会話では新しい送信を開始できません。完了、停止または失敗を確認してから送信します。
07

会話履歴を開く、継続する、削除する

  1. 「会話履歴」を押す

    Panel Mode では履歴領域を展開します。専用画面では左側に常時表示されます。

  2. 会話題名を選ぶ

    Session の Message、添付、Task 状態、回答を読み込みます。読み込みに失敗した場合は再読込を押します。

  3. 同じ話題を継続する

    会話末尾の入力欄から追加依頼を送ります。過去の Message は現在 Session の Context として使用されます。

  4. 不要な会話を削除する

    履歴行の削除操作を押し、確認 Modal で会話を削除を実行します。削除後は履歴から外れ、選択中だった場合は別の会話へ移ります。

  5. 長い会話を移動する

    右側の Quick Navigation Mark に Focus または Hover すると質問と回答の Preview が出ます。押すと該当する利用者メッセージへ移動します。末尾から離れた場合は最新の会話へ移動を使用します。

08

問題が起きたときの確認順

  • 送信できない会話が選択済みか、文字または READY 添付があるか、Upload 中または回答生成中でないか確認します。
  • 添付できない件数、単一 Size、合計 Size、現在 Task の状態を確認します。
  • AI が一時利用不可入力内容は保持されます。画面の案内を確認し、少し待って再送します。
  • AI 接続設定エラー入力内容を保持したまま管理者へ連絡し、Model API 設定を確認します。
  • 再接続が続く会話を再読込し、同じ Task の状態を確認します。新しい会話を重複作成しません。
  • 停止できない停止操作を再実行し、継続する場合は Task ID と時刻を管理者へ伝えます。
回答の利用前確認AI 回答に含まれる数値、固有名詞、法令、契約条件、公開範囲は、根拠資料と担当者判断で確認してください。
