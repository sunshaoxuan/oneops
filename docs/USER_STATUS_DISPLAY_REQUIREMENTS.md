# 利用者状態表示要件

更新日: 2026-08-05

## 目的

ユーザー管理で利用者状態を内部列挙値のまま表示せず、現在の画面言語に対応した業務文言で表示する。

## 表示規則

| 内部値 | 日本語 | 簡体字中国語 | 英語 |
| --- | --- | --- | --- |
| `PENDING` | 承認待ち | 待审核 | Pending approval |
| `ACTIVE` | 有効 | 启用 | Active |
| `SUSPENDED` | 停止 | 停用 | Suspended |

一覧の状態 Tag とユーザー権限編集画面の状態選択肢は同じ表示規則を使用する。

## データ契約

API Request、API Response 及びデータベースでは `PENDING`、`ACTIVE`、`SUSPENDED` を維持する。表示文言を強参照又は判定値に使用しない。

## 受入条件

1. 日本語画面の一覧と編集選択肢に英大文字の内部値が表示されない。
2. 日本語では承認待ち、有効、停止を表示する。
3. 状態を選択して保存する際は対応する内部値を送信する。
4. 英語と簡体字中国語でも同じ内部値を各言語の文言で表示する。
5. Portal 試験、Production Build、正式画面、Console、Layout 及び Screenshot を確認する。

## 最終受入

本書の目的、表示規則、データ契約及び受入条件を先頭から逐項確認する。不合格項目を修正した場合は最終受入全体を先頭から再実行する。
