# 最終確認票

## 対象

Portal の再読み込み、ブラウザーの戻る操作、進む操作で現在機能を維持する。

## 実装

1. 第 1 階層画面へ安定 URL を割り当てた。
2. 基本台帳とシステム管理の第 2 階層機能へ安定 URL を割り当てた。
3. メニュー遷移をブラウザー履歴へ追加した。
4. 初回表示と再読み込みで URL から機能を復元した。
5. `popstate` から戻る操作と進む操作を復元した。
6. 権限のない機能と未知 URL を安全な機能へ正規化した。

## 品質確認

Node.js 119 件、Builder Python 4 件、Portal 80 件、TypeScript 検査、本番ビルドが成功した。公開と nginx 構文検査も成功した。

実ブラウザーでは問合支援とシステム操作監査の再読み込み、2 段階の戻る操作、2 段階の進む操作を確認した。各操作で URL と表示機能が一致し、コンソールの error、warning、warn は 0 件だった。

## 判定

受入条件を満たしている。
