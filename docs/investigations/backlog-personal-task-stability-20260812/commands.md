# 実行コマンド記録

1. `git fetch origin master` と HEAD、`origin/master`、作業ツリー差分の確認
2. `rg` による個人タスク画面、API、Route、Connector、Repository、Migration、Test の追跡
3. PostgreSQL の Backlog 接続状態及び同期 Run の非秘密情報確認
4. 暗号化済み接続を Repository 境界で読み、Backlog API の本人、プロジェクト、課題一覧を読取専用で最小化確認
5. Backlog Developer API の Issue List 及び Error Response の公式資料確認
6. Gateway 個人タスク試験、Portal 試験、製品 Build、実 API 同期、ブラウザー受入

API Key、暗号化値及び Database 接続パスワードは記録対象外とした。
