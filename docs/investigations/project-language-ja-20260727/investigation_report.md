# プロジェクト第一言語の日本語化調査

## 目的

OneOps プロジェクトの第一言語を日本語として明文化し、管理対象の文書、説明、コードコメント、版数情報へ反映する。

利用者との会話言語はこの規則の対象外とする。画面の中国語および英語翻訳、外部連携データ、テスト用業務データ、API の固定値、第三者ライセンス原文は、それぞれの用途に必要な言語を維持する。

## 調査範囲

- GitHub の入口となる `README.md`、`AGENTS.md`、`CHANGELOG.md`
- プロジェクト規則および版数管理文書
- アプリケーションの README
- GitHub 初回登録に関する直近の調査記録
- 管理対象ソースコード内の説明コメント
- Web 層 Agent Gateway 技術仕様書
- 版数表示およびパッケージ版数

## 実施内容

1. 第一言語と例外範囲を `AGENTS.md` および `docs/PROJECT_RULES.md` に記録した。
2. GitHub 入口文書と版数管理文書を日本語へ統一した。
3. 管理対象ソースコードの説明コメントを日本語へ統一した。
4. 文書およびコメントを検査する自動テストを追加した。
5. Web 層 Agent Gateway 技術仕様書を日本語版へ置き換えた。
6. 版数を `0.2.1` に更新した。

## 適用方針

新規作成または実質的に更新する正式文書と説明コメントは日本語で記述する。履歴証跡は証拠性を守り、実質的な更新時に内容と責任範囲を確認した上で日本語化する。

## 検証上の制約

DOCX は文書構造、JSON 例、A4 用紙設定、簡体字標識、ZIP パッケージ整合性を検査した。実行環境に LibreOffice がなく、Microsoft Word の COM 経由でも PDF が生成されなかったため、画像化による目視検証は完了していない。
