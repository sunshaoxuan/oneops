# 实现回执

状态：实现与验收完成。

## 完成范围

1. 增加 `inquiries.use` 权限及系统角色授权。
2. 增加加密真实网站设置、辅助任务和事件数据表。
3. 增加真实 UPDS 登录、查询、详情、附件代理与标准化解析。
4. 增加 Model 与 Agent Gateway 的独立 `InquiryAnalysisProvider` 消费层。
5. 增加问询支援查询页、大型详情抽屉、问题分区、左右聊天布局和按需 AI 面板。
6. 增加系统级 UPDS 登录和分析 Provider 设置页。
7. 更新 `INQUIRY_SUPPORT_REQUIREMENTS.md`。
8. 增加与用户管理平级的系统操作审计节点，覆盖登录、业务 API 和 AI 辅助过程。
9. 增加 Provider Token 用量保存与展示，未返回时明确标记为未提供。
10. 规范化 AI 草案转义换行，编辑和复制均使用真实换行。
11. 调整查询默认日期为开始日期留空、结束日期为浏览器本地当天。
12. 调整查询结果客户列，只显示客户名；提问人保留在工单详情中。

## 安全与边界

1. 登录密码使用 AES-GCM 加密保存。
2. Cookie、CSRF Token 和密码不进入业务响应与 Model 输入。
3. 联系方式在 Model 输入前脱敏。
4. 工单正文作为不可信证据处理。
5. 第一版只生成和复制草案，不向真实网站发布。
6. 现有 AI 设置和 Agent Gateway 实现文件未修改。

## 验证

完整测试、生产构建、真实网站查询、真实详情、人工 AI 调用、系统审计查询、发布、Nginx 配置、健康检查、浏览器控制台和截图均已通过。查询页的日期默认值、客户表头和实际客户单元格结构已在发布页面复验。详细结果见 `test_results.md`。

## 回滚

回滚本功能提交并重新发布前端与网关。迁移新增表可以保留为空表；如需删除，应先备份 `inquiry_source_settings` 与 `inquiry_assist_runs`，再按外键顺序删除事件、辅助任务和设置表。
