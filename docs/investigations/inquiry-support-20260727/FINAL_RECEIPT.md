18. 修复客户提问、追加提问、内部讨论与公开回复在解析阶段丢失 `<br>` 和段落边界的问题。

## 安全与边界

1. 登录密码使用 AES-GCM 加密保存。
2. Cookie、CSRF Token 和密码不进入业务响应与 Model 输入。
3. 联系方式在 Model 输入前脱敏。
4. 工单正文作为不可信证据处理。
5. 第一版只生成和复制草案，不向真实网站发布。
6. 现有 AI 设置和 Agent Gateway 实现文件未修改。

## 验证

完整测试、生产构建、真实网站查询、真实详情、人工 AI 调用、系统审计查询、发布、Nginx 配置、健康检查和浏览器控制台均已通过。查询页的日期默认值、客户表头、实际客户单元格结构、内容与 No. 条件、AI 历史按钮、正文换行、CLOSED 客户评价、问合等级及响应式布局已在发布页面复验。本轮真实详情包含客户数据，未保存整页截图；视觉结构通过 DOM 和计算样式验证。详细结果见 `test_results.md`。

## 回滚

回滚本功能提交并重新发布前端与网关。迁移新增表可以保留为空表；如需删除，应先备份 `inquiry_source_settings` 与 `inquiry_assist_runs`，再按外键顺序删除事件、辅助任务和设置表。
