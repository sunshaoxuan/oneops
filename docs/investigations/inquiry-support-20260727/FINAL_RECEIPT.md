## 安全与边界

1. 登录密码使用 AES-GCM 加密保存。
2. Cookie、CSRF Token 和密码不进入业务响应与 Model 输入。
3. 联系方式在 Model 输入前脱敏。
4. 工单正文作为不可信证据处理。
5. 第一版只生成和复制草案，不向真实网站发布。
6. 现有 AI 设置和 Agent Gateway 实现文件未修改。
7. 附件原始文件和解析正文不写入数据库；解析结果仅在网关内存中短期缓存。

## 回滚

回滚本功能提交并重新发布前端与网关。迁移新增表可以保留为空表；如需删除，应先备份 `inquiry_source_settings` 与 `inquiry_assist_runs`，再按外键顺序删除事件、辅助任务和设置表。
