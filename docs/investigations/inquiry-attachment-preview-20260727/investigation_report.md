# 問合支援 添付ファイル表示 調査報告

## 目的

問合支援の添付ファイルを業務上すぐ利用できる形へ整理し、不要な本文抽出と OCR を廃止する。

## 現行ソースの確認

| 対象 | 確認結果 |
| --- | --- |
| 添付情報 | 実サイトの詳細 HTML から安定した添付 ID、ファイル名、形式、サイズを取得できる |
| ファイル本体 | 実サイト認証後、固定 S3 オリジンへリダイレクトされる場合がある |
| PDF | ブラウザー内蔵ビューアーで表示するため Range 要求の中継が必要 |
| Word と Excel | ブラウザーの Office 表示機能を利用し、常にダウンロード操作を併設する |
| その他形式 | 同一オリジン上の任意コンテンツ実行を避けるため直接ダウンロードとする |

## 採用設計

1. 画像、PDF、Word、Excel の添付操作は、問合せ詳細より上位に重なるドロワーを開く。
2. 画像は `img`、PDF、Word、Excel は同一オリジンの `iframe` で表示する。
3. その他形式はプレビューを開かず、`Content-Disposition: attachment` で直接ダウンロードする。
4. プレビュー対象拡張子を Gateway と Portal の双方で固定定義する。
5. 添付本文の抽出、OCR、解析状態、再解析 API、解析キャッシュを削除する。
6. AI 支援には添付本文を渡さず、ファイル名と形式のみを渡す。
7. 実サイト Cookie は S3 へ送信せず、許可済みオリジン以外へのリダイレクトを拒否する。

## セキュリティ境界

プレビュー対象は画像、PDF、Word、Excel に限定する。HTML、SVG、スクリプト、アーカイブなどは必ずダウンロードとして返す。レスポンスには `private, no-store` と `nosniff` を付与し、ファイル名はレスポンスヘッダーへ設定する前に制御文字と予約文字を除去する。
