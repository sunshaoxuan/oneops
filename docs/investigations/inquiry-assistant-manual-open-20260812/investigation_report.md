# 問合支援 AI クイックチャット手動表示 調査報告

更新日: 2026-08-12

## 調査結果

1. `App.tsx` は問合支援を含む通常画面へ `AiAssistantChat` を `floating` モードで常時マウントする。
2. `AiAssistantChat.tsx` は従来、利用者単位の Local Storage に保存された `open=true` を初期値へ使用していた。
3. `inquiryContext.ticketNo` を検出した `useEffect` が `setOpen(true)` を実行し、問合せ詳細を開くだけでチャットを強制展開していた。
4. 同じ Effect の会話照合、最後の会話選択、票専用会話作成は `visible` が true の場合に実行されるため、表示制御と会話準備を分離できる。

## 修正契約

浮動モードの初期状態は常に閉じる。工单上下文不会自动改变窗口可见状态。右下 AI 图标的点击打开和窗口关闭按钮的关闭行为保持。窗口打开后，当前票号的最后会话恢复或新会话创建继续执行。

## 受入条件

1. 进入问合支援详情时浮动聊天不自动出现。
2. 点击 AI 图标后浮动聊天出现。
3. 点击关闭后浮动聊天消失，工单上下文不丢失。
4. `/ai-assistant` 全屏模式仍然常驻显示。
