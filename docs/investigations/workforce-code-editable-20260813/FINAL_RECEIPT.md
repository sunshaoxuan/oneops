# 最終受入回执

## 最初の目的

物理 ID を持つ社内部門及び業務職責の Code を編集可能にし、強参照を物理 ID と外部キーで維持する。

## 最終受入一覧

| 項目 | 成果物 | 証拠 | 判定 |
|---|---|---|---|
| 部門 Code を編集可能にする | 部門編集 Modal | E01、E06 | 合格 |
| 職責 Code を編集可能にする | 職責編集 Modal | E01、前端回帰試験 | 合格 |
| 物理 ID だけで更新対象を特定する | backend 更新 SQL | E02、E04 | 合格 |
| Code 変更後も強参照を維持する | 実 PostgreSQL 試験 | E03 | 合格 |
| Code の形式及び一意性を維持する | DB 制約、重複検証 | E02、migration | 合格 |
| 要件文書を更新する | 要件文書 | E05 | 合格 |
| 関連試験及び build を成功させる | test results | `test_results.md` | 合格 |
| 対象環境へ交付する | 継続交付 | E07 | 合格 |
| 実画面、Console、Screenshot を確認する | Browser 証拠 | E06、console 0 件 | 合格 |
| Browser で保存連続操作を記録する | Browser 操作 | `TS2_VERIFY` 反映後に `TS2` へ復元 | 合格 |

## 判定

返工後に一覧の先頭から全項目を再確認し、全項目が合格した。成果物は最初の目的及び明示制約に一致する。
