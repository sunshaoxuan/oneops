# 個人設定による大見出し最小化 調査及び実装報告

## 目的

プロフィールの一つの個人設定から、対応する全画面の大見出しを面包屑形式へ統一し、利用者単位で継続利用できるようにする。

## 調査結果

既存のプロフィール保存は表示名だけを `PUT /api/work-center/v1/auth/profile` で更新していた。利用者台帳には画面見出し設定が存在しなかった。大見出しは顧客情報、個人タスク、問合支援、基本台帳、システム管理及び占位機能の六つの入口で `portal-page-hero` を使用していた。

## 実装

1. `users.compact_page_headings` を既定値 `false` の利用者設定として追加した。
2. Profile API、Session の `AuthUser` 及びプロフィール画面へ `compactPageHeadings` を追加した。
3. 三言語で「見出しを最小化（省スペース）」と説明を表示する。
4. 全大見出しを `PortalPageHero` へ統一した。
5. 設定が有効な場合は共通 Provider が `nav`、`ol` 及び `aria-current=page` を持つ「ホーム / 現在画面」を出力する。
6. 大見出し内に存在した業務操作は面包屑の一部にせず、直後の独立操作領域へ保持する。

## 境界

設定は利用者物理 ID に紐づく。画面ごとの設定、ブラウザー Local Storage、互換 Layer 及び Fallback は追加しない。既定値は無効であり、既存利用者の表示を自動変更しない。
