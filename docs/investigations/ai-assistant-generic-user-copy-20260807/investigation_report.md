# AI助手の利用者向け一般表現 実装記録

## 1. 目的

一般利用者には AI と会話する機能であることだけを示し、CAG、Model API、Agent Gateway などの内部接続方式を空状態、待機状態及び説明文へ表示しない。

## 2. 対象

- AI助手の空状態
- AI 応答の待機状態
- 問合せ Context の利用説明
- 第 1 階層 AI助手の機能説明
- 日本語、中国語及び英語

管理者向け接続設定、操作監査、内部 API 契約及び技術文書は運用上の識別が必要なため、内部方式の名称を維持した。

## 3. 実装

一般利用者向け Copy を CAG 固有表現から AI 表現へ統一した。空状態は「新しい話題を作成して、AI との会話を始めます。」、待機状態は「AI の応答待ち」とした。問合せ Context は AI の参照情報として使用する説明へ変更した。

## 4. 検証

Gateway、Worker、Portal、Spring、運用 Script 及び正式 Build に合格した。Version 0.15.9 を正式 Runtime へ公開した。

正式 Browser の AI助手空状態で新しい日本語 Copy を確認した。AI助手の一般利用者領域に CAG、Model API、Agent Gateway が存在しないこと、Console の error 及び warning が 0 件であることを確認した。

## 5. 結論

一般利用者向け UI は内部接続方式を説明せず、AI と会話する機能として一貫した表現になった。管理運用に必要な技術的識別は管理者及び内部境界へ限定して維持される。
