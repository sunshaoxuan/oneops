# Portal ブランド表示とナビゲーション収縮調査記録

## 目的

参考画面の視覚言語に合わせ、左側ナビゲーションの OneOps ブランド文字と副題へ主色を適用し、ナビゲーション収縮時に HR ロゴを表示せず OneOps 文字を保持する。

## 実装経路

1. `App.tsx` の `Brand` コンポーネントが展開状態と収縮状態を受け取る。
2. 展開状態だけで HR ロゴと区切り線を描画し、OneOps 文字と副題を常に描画する。
3. `styles.css` が OneOps を橙色、副題を青緑色へ設定する。
4. 収縮状態ではブランド画像と副題を CSS と条件付き描画で除外し、OneOps 文字を中央へ配置する。
5. `layout.test.ts` が条件付きロゴ描画、文字色、収縮時表示及びページ幅の契約を確認する。
6. Production build、静的公開、実ページ DOM、コンソール及びスクリーンショットで最終動作を確認する。

## 状態別表示

| 状態 | HR ロゴ | OneOps | 副題 | 確認 |
|---|---|---|---|---|
| 展開 | 表示 | 橙色で表示 | 青緑色で表示 | 合格 |
| 収縮 | 非表示 | 橙色で中央表示 | 非表示 | 合格 |

## 既知の制約

今回の変更はブランド表示と左側ナビゲーションの表示状態に限定する。メニュー項目、権限、接続状態、保存済み収縮設定及びページ遷移の契約は変更しない。
