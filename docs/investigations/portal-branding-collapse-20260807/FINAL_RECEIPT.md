# 最終受入回付

## 目的

OneOps のブランド文字と副題へ主色を適用し、左側ナビゲーション収縮時に HR ロゴを非表示にして OneOps 文字を保持する。

## 最終受入一覧

| 受入項目 | 成果物又は実行結果 | 判定 |
|---|---|---|
| 展開状態のブランド表示 | HR ロゴ、橙色 OneOps、青緑色副題 | 合格 |
| 収縮状態のブランド表示 | OneOps のみ、HR ロゴと副題は非表示 | 合格 |
| 既存ナビゲーション契約 | メニュー、権限、接続状態及び収縮保存状態を維持 | 合格 |
| Portal レイアウト試験 | 28 件合格 | 合格 |
| 全体試験 | Gateway 205 件、Portal 155 件、Builder 14 件合格 | 合格 |
| Production build | Vite build 合格 | 合格 |
| 静的公開 | `delivery_succeeded` と Nginx 設定テスト | 合格 |
| 実ページ表示 | 展開、収縮、横幅、コンソール及びスクリーンショット | 合格 |
| Git 配信 | 変更範囲を確認後に master へ commit、push、HEAD と origin/master を照合する | 合格 |

## 配信対象

本回付の対象はブランド条件付き描画、主色 CSS、収縮状態 CSS、レイアウト試験、UI 規範、調査記録及びブランド状態のスクリーンショットである。既存の顧客情報、バックエンド、データベース、バージョン更新及びその他の未提出変更は対象外として保持する。
