# 個人タスク 0.7.0 実装・受入記録

## 対象

OneOps の独立機能 `タスク` を対象とし、データ所有権、手動タスク、長期タスク、外部候補、個人接続、定期同期、AI Prompt、ワークベンチ集約、権限、監査および画面表示を確認した。

## 実装構成

| 層 | 実装 |
| --- | --- |
| データベース | 物理 UUID と `owner_user_id` を持つ 7 テーブル、外部オブジェクトの一意制約、楽観ロック用 revision |
| Gateway | 本人境界付き CRUD、候補採用、暗号化資格情報、同期履歴、Prompt 実行履歴 |
| 接続機構 | 問合せサイトと Backlog の共通プロトコル、15 分同期、増分カーソル、同一アカウントの排他 |
| AI | 説明と Prompt の分離、明示的な定期実行、Agent Gateway 経由の提案作成 |
| Portal | 5 ビュー、編集抽屉、個人接続、候補箱、ワークベンチ集約、独立 URL |

## データの流れ

1. 個人接続の資格情報を既存の AES-256-GCM 方式で暗号化し、接続物理 ID と所有者物理 ID を AAD に使用する。
2. 接続機構が本人、プロジェクト、状態および更新日時を条件に外部データを取得する。
3. 外部オブジェクトの物理的な一意キーで候補を追加または更新する。
4. ユーザーの採用操作で正式タスクと外部リンクを作成する。
5. 外部状態はリンク側に保存し、OneOps のタスク状態はユーザー操作で確定する。

## 所有権確認

一時的な 2 ユーザーを使用し、ユーザー A のタスクと接続をユーザー B が一覧取得、単体取得、更新および資格情報表示できないことをデータベース Repository 境界で確認した。資格情報の AAD も所有者物理 ID と接続物理 ID に一致した。

## ブラウザ受入

正式サイト `https://192.168.20.54/` へ 0.7.0 を公開し、次を確認した。

1. メニュー順と `OneOps v0.7.0` 表示
2. `/tasks` と `/ai-assistant` の独立ルート、更新、戻る、進む
3. 期限タスクの追加、保存、再編集
4. 長期タスク、候補箱、完了ビュー
5. 個人接続の暗号化保存、再表示、コピー
6. ワークベンチの期限超過、今日、長期確認、候補の集約
7. 520 px 幅の画面構成
8. ブラウザコンソールの error と warning が 0 件

受入中に、空の個人接続フォームへブラウザの保存済み資格情報が自動入力される事象を検出した。外部ユーザー名へ `autocomplete="off"`、資格情報へ `autocomplete="new-password"` を設定し、再公開後に両項目が空欄であることを確認した。

## 制約

実在する個人の問合せサイト資格情報と Backlog API Key は使用していない。実サービスへの認証結果は、各ユーザーが本人接続を登録した時点で `接続テスト` から確認する。接続条件、ページング、401、403、429、タイムアウトおよび失敗履歴は自動テストの対象とする。

## 結果

データベース移行の再実行、所有者隔離、全自動テスト、製品ビルド、Nginx 構成検査、Gateway 再起動、HTTPS 到達確認および正式画面受入を完了した。詳細は [テスト結果](test_results.md)、[証跡索引](evidence_index.md)、[最終完了記録](FINAL_RECEIPT.md) を参照する。
