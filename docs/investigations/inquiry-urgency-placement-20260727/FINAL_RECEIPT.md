# 実装回执

状態: 実装、公開、検証完了

## 実装内容

1. 問合せ詳細のタイトル行から緊急度バッジを削除した。
2. 基本情報の「緊急度」を唯一の表示位置とした。
3. 有効な緊急度が「至急」の場合だけ、値を赤色の太字で表示する。
4. 「一般」など他の緊急度は通常表示を維持する。
5. Windows の CRLF と LF の双方で動くように、CSS とソース検査の改行依存を解消した。

## 検証

Node.js 116 件、Builder Python 4 件、Portal 73 件、TypeScript と本番ビルドが成功した。公開処理、Nginx 設定検査、Gateway 健全性検査、HTTPS 入口検査が成功した。

公開画面の問合せ No. 94056 で、タイトル行に緊急度バッジが存在しないこと、基本情報の「至急」が赤色の太字で表示されることを確認した。ブラウザーコンソールのエラーと警告は 0 件である。
