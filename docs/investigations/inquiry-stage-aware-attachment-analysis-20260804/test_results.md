## 回帰観点

- 顧客公開回答が一件もない場合は `PRE_RESPONSE` となる。
- 過去回答があり、最新質問が未回答の場合は `IN_PROGRESS` となる。
- 最新質問に回答がある OPEN は `RESPONSE_REVIEW` となる。
- CLOSED は `CLOSED_REVIEW` となる。
- 対応中にサービス品質文字列、顧客評価推測、誤った段階を返す応答は拒否する。
- PPTX の文字列と画像を抽出し、重複添付を 1 件として扱う。
- 未対応形式を解析済みとして扱わない。
- Model API へ画像を高精度入力として渡す。
- 空の顧客評価領域と対応中のサービス品質領域を表示しない。
