# 完了記録

## 実装

1. `TICKET` アンカーを追加した。
2. 問合せ全体の AI 補助領域を問題ブロック外へ移した。
3. 顧客質問と返信の電球を位置分析として維持した。
4. 問合せ全体 Prompt が保存用 `questionKey` に制限されないようにした。
5. 問合せ全体の履歴を独立領域へ復元した。
6. 既存の `NEXT_REPLY` 履歴を元位置へ保持した。
7. AI助手の重複した最小化操作を削除し、閉じる操作へ統一した。
8. クイックナビゲーションの波形をホバーとキーボードフォーカス中だけ表示し、クリック選択を黒い長線として独立保持した。
9. AI助手の Tooltip と確認ポップアップを浮動ウィンドウより前面へ統一し、右端の問合せを開く提示を左方向へ展開した。
10. 問合せ全体の入口を `FULL_TICKET` の問合せ全体分析へ変更した。
11. 各回の回答対応度、見落とし・再質問・待ち時間、顧客評価との関係、全体品質・リスク・最終結論、是正対応を独立表示した。
12. 待ち時間を記録時刻から計算し、最終顧客公開回答の有無で最終結論を制御した。
13. `FULL_TICKET` の返信案生成を停止した。
14. 旧マイグレーション再実行時の `TICKET` 制約違反を修正し、Gateway を復旧した。

## 検証

Gateway 133 件、Portal Shell 113 件、Builder Worker 4 件のテスト、TypeScript と Vite のビルド、公開、Nginx 構文、内部と公開 HTTPS の Gateway ヘルスを確認した。ブラウザー検証はログイン完了後に確定する。
