# 命令记录

1. 使用只读表格分析检查机构别制品资料中的四个目标机构。
2. 执行 EnvPortal 增强导入预演，并生成任务内临时报告。
3. 执行 `pnpm check`，验证网关、前端、TypeScript 和生产构建。
4. 使用 `pg_dump -Fc` 创建增强前数据库备份。
5. 执行 `scripts/import-envportal.mjs --apply` 创建批次 2。
6. 查询批次、环境分组、端点、制品版数关系和脱敏字段。
7. 重复执行增强导入，验证批次幂等性。
8. 使用 `scripts/publish-portal.ps1` 发布并重启网关。
9. 在浏览器中验证筑波大学和大阪广域水道企业团页面。
10. 检查浏览器开发日志并保存页面截图。
