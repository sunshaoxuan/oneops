# クイックアシスタント説明文配置 調査報告

更新日: 2026-08-12

## 調査対象

第2階層 Menu の複数カードで、説明文の末尾一文字と句点だけが次行へ孤立する原因と共通修正方法を調査した。

## 確認結果

1. 添付画像では「課題分解」と「確認一覧作成」の説明が本文一行の容量をわずかに超え、「す。」だけが次行へ配置されていた。
2. 説明文は `ai-assistant-shortcut-menu-item` 内の `small` 要素で表示され、従来は通常の自動折返しだけが適用されていた。
3. 購読 Icon は見出し行に配置されている。本文側に全幅使用を明示する契約が存在しなかった。
4. 末尾一文字の孤立を要求する業務規則又は日本語組版規則は存在しない。通常の折返し位置がカード幅の境界と一致した結果である。

## 実装

説明文を Block として本文幅の全体へ広げ、`line-break: strict` で日本語禁則処理を適用し、`text-wrap: pretty` で短すぎる末行を避ける折返し候補を選択する。文言ごとの固定改行や高さによる切捨ては導入しない。

## 期待結果

既存12件及び今後追加される説明文に同じ配置規則が適用され、一般的な表示幅で一文字又は句点だけの孤立行を避けつつ全文を表示する。
