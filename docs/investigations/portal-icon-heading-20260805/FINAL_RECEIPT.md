# 最終受入回付

## 目的

参考画面のデザイン言語に合わせ、機能アイコンが欠けていた Portal のページ見出しと管理区画見出しを補充する。

## 最終受入一覧

| 受入項目 | 成果物又は実行結果 | 判定 |
|---|---|---|
| ページレベル見出しへ機能アイコンを表示 | 顧客情報、個人タスクの `portal-page-hero-icon` | 合格 |
| 管理区画へ機能アイコンを表示 | 基本台帳、AI 設定、外部タスク、業務部門及び問合検索テンプレート | 合格 |
| 業務意味に対応するアイコンを選択 | Ant Design Icons の機能別選択 | 合格 |
| 共通寸法と色を維持 | 62px と 48px の共通 CSS | 合格 |
| 狭い画面の配置 | 640px 実ページとスクリーンショット | 合格 |
| 自動試験 | Portal 144 件、全体 175 件及び Builder 14 件 | 合格 |
| production build | Vite production build | 合格 |
| 公開状態 | `delivery_succeeded` と Nginx 設定テスト | 合格 |
| ブラウザー表示 | 実ページ DOM、コンソール、デスクトップ及び窄屏証跡 | 合格 |
| 配信後の Git 状態 | 変更範囲を確認後に master へ commit、push、HEAD と origin/master を照合する | 実行中 |

## 配信対象

本回付の配信対象は機能アイコンの実装、共通 CSS、関連試験、設計規範、調査証跡及び UI スクリーンショットである。既存の顧客情報業務変更、外部タスク設定変更、API クライアント変更及びその他の未提出変更は対象外として保持する。
