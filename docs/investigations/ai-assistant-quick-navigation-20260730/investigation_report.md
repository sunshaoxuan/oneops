# AI助手クイックナビゲーション実装調査

## 目的

長い会話で現在位置を把握し、任意の利用者メッセージまたは AI 回答へ短い操作で移動できる固定ナビゲーションを、AI助手画面とフローティング画面へ共通実装する。

## 実装結果

1. 会話スクロール領域の左側に固定ナビゲーションを配置した。
2. 利用者メッセージと AI 回答を別々の目盛りとして表示した。
3. 表示位置の 38 パーセント地点を基準に現在のメッセージを判定し、該当する目盛りを強調する。
4. 目盛りのフォーカス可能なボタンに、発言者と順番を含むアクセシブル名称を付与した。
5. 目盛りを選択すると対象メッセージが会話領域の中央へ移動する。
6. ホバー時に発言者、順番、本文の短い要約を表示する。
7. Markdown 記号とコードブロックを要約から整理し、長い本文は 72 文字で省略する。
8. モーション低減設定ではスムーズスクロールを使用しない。

## 境界

本変更は OneOps の AI助手表示と操作のみを対象とする。CAG のコード、プロセス、会話 API、保存データは変更しない。

## 確認結果

1. AI助手画面とフローティング画面の双方で 12 個のナビゲーション項目を確認した。
2. 8 番目の項目を選択すると、スクロール位置が 0 から 1869 へ移動し、活動項目も同じ項目へ更新された。
3. AI助手画面は表示幅 1280 ピクセルに対して本文幅 1280 ピクセル以内だった。
4. フローティング画面は会話領域幅とメッセージ領域幅がともに 423 ピクセルで、横方向のはみ出しはなかった。
5. 両画面のブラウザコンソールに警告とエラーはなかった。
