## 结论

EnvPortal 当前工作区包含 5 条环境、3 条 RDP 连接和 5 条遗留标签关联。4 条环境可通过组织机构 Code 唯一映射到 OneOps。1 条“标准版”环境没有目标组织机构。1 条 RDP 可通过机构和主机映射到已导入环境，其余 RDP 与标签记录缺少可靠目标。

本次建立了脱敏迁移暂存表、幂等导入脚本和自动化测试。正式批次 1 新增 4 条环境，暂存 13 条来源记录。31 个已填写的凭据类字段只记录数量，字段名和值均未保存到暂存负载。

## 映射规则

1. 组织机构 Code 是首要匹配键。
2. 来源 Code 为空时才允许规范化名称匹配。
3. 来源 Code 存在但无法匹配时进入待确认区。
4. 活跃环境同名时进入冲突区，导入器不覆盖现有环境。
5. 缺失用途时登记为 `OTHER`，最后确认日保持空值。
6. RDP 和标签没有正式目标模型时保留在暂存区。
7. 登录 ID、密码和数据库用户字段全部排除。
