# ロール権限マトリクス可読性改善報告

## 指摘事項

1. 操作列を中央揃えした状態で名称と Code を表示していたため、文字数によってチェックボックスの開始位置が変化していました。
2. 未登録の翻訳はデータベースの中国語名称へフォールバックしていたため、日本語画面に中国語が混在していました。
3. `read`、`write`、`use` を直接利用者向け概念として表示していたため、`read` と `use` の境界が伝わりにくい状態でした。
4. 組込みロールの編集フォームはデータベースの原文を表示していたため、現在言語と異なる名称と説明が表示されていました。

## 対応

権限セルを固定位置のチェックボックスだけに整理し、機能ノードも現在言語の名称だけを表示しました。権限 Code と詳細名称はツールチップへ移動しました。

利用者向け操作名称を「閲覧」「管理」「実行」へ変更しました。「閲覧」は情報確認、「管理」はデータや設定の変更、「実行」は問合検索や AI 支援などの業務処理起動を表します。保存する権限 Code は既存の `read`、`write`、`use` を維持します。

不足していた環境認証情報、AI 設定、問合支援の日本語、中国語、英語名称を追加しました。組込みロールの名称と説明は現在言語で読み取り専用表示し、権限保存時にはデータベースの原文を保持します。
