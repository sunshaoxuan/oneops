# バージョン管理

更新日: 2026-07-27

## バージョン番号

OneOps は Semantic Versioning を使用し、`メジャー.マイナー.パッチ` の形式で表します。

- メジャー: データ、インターフェース、運用方法に互換性のない変更がある場合
- マイナー: 後方互換性を保った機能を追加する場合
- パッチ: 後方互換性を保った問題修正を行う場合

ルートの `VERSION` に現行バージョンを保存します。リリース時は次の値を同期します。

- `VERSION`
- `CHANGELOG.md`
- `app/package.json`
- `app/apps/portal-shell/package.json`
- Portal の画面表示バージョン

## リリース手順

1. `origin/master` を取得して差分を確認する。
2. コード、関連文書、バージョン記録を更新する。
3. 全テスト、本番ビルド、必要なリリース検証を実行する。
4. 変更をコミットし、`origin/master` へ直接プッシュする。
5. 正式バージョンに `v<version>` タグを作成してプッシュする。
6. ローカル `HEAD`、`origin/master`、タグの参照先が一致することを確認する。

ユーザーが明示的に指示した場合に限り、別ブランチまたは Pull Request を作成します。
