# OneOps UI 间距规范

更新时间：2026-07-27

## 适用范围

本规范适用于 OneOps 一级功能页、系统管理、基本台账、设置表单、列表卡片和卡片操作区。新增页面与既有页面调整均应复用本文定义的间距层级和共用样式。

## 基础间距

OneOps 使用以下基础间距：

| Token | 数值 | 用途 |
|---|---:|---|
| `--oneops-space-xs` | 8px | 按钮组、标签和紧凑元素 |
| `--oneops-space-sm` | 12px | 小型区块内部间距 |
| `--oneops-space-md` | 16px | 关联内容、图标与文字 |
| `--oneops-space-lg` | 20px | 标题与内容、操作栏上边距 |
| `--oneops-space-xl` | 24px | 管理内容区和标准卡片内边距 |

业务页面不得新增含义重复的 17px、18px、22px、23px 等局部桌面间距。响应式布局可以使用统一的 18px 紧凑内边距。

## 管理工作区

1. `management-shell` 只负责导航与内容区的外层容器。
2. 只有 `management-shell` 的直属 Card Body 使用 0 内边距。
3. 管理内容区桌面内边距为 24px。
4. 管理内容区中的标准卡片，Card Head 和 Card Body 水平内边距均为 24px。
5. 720px 及以下，管理内容区和标准卡片内边距统一为 18px。
6. 禁止使用 `.management-shell .ant-card-body` 等后代选择器清空全部嵌套卡片内边距。
7. 表格或列表确需通栏展示时，必须使用组件专属类明确声明，并为工具栏、空状态和分页区分别保留标准内边距。

## 页面标题与卡片

1. 页面内容标题与首张卡片间距为 20px。
2. 同级卡片之间的间距为 20px。
3. 卡片标题区与表单字段间距为 24px。
4. 表单桌面列间距为 24px。
5. 同一页面的同级卡片必须使用相同的 Card Head、Card Body 和 Footer 结构。

## 卡片操作栏

1. 设置类卡片统一使用 `management-card-footer`。
2. 操作栏使用 1px 顶部分隔线和 20px 上内边距。
3. 更新时间等元数据位于左侧，操作按钮位于右侧。
4. 没有元数据时，按钮仍保持同一纵向位置和卡片底部间距。
5. 按钮间距为 8px，设置类按钮最小宽度为 112px。
6. 辅助操作位于主操作左侧，主操作位于最右侧。
7. 操作栏不得使用绝对定位，也不得依赖卡片内容高度定位。

## 验收

1. 浏览器测量 Card Body 桌面四边内边距均为 24px。
2. 同级卡片的操作栏上边距、按钮间距和右侧内边距一致。
3. 有更新时间与无更新时间的卡片，按钮纵向位置遵循同一 Footer 结构。
4. 设置页面、表格页面和基本台账页面不受外层 Card Body 清零规则影响。
5. 页面不存在横向溢出。
6. 自动化测试、生产构建、真实页面、浏览器控制台和截图验证通过。

## 参考画面から取り入れるページヘッダー表現

2026-08-05 の「製品構築」画面を、Portal の主要画面と管理区画における共通の視覚基準として扱う。

1. ページ上部は白色を基調とした角丸ワークスペースとして表示し、本文領域と明確に区切る。
2. 小見出しは橙色の大文字又は業務ラベルで表示し、主見出しは濃紺系の太字で表示する。
3. 背景装飾には橙色と青緑色の円形要素を低いコントラストで使用し、業務情報の可読性を優先する。
4. 顧客名、操作ボタン及び状態情報はヘッダーの右側へ配置できる。狭い画面では本文の下へ積み重ねる。
5. ページヘッダーの実装は `portal-page-hero`、管理区画の見出しは `portal-section-heading` を使用する。
6. この表現はデータ取得、保存、ルーティング、認可及び API 契約を変更しない。

## 機能アイコンの表示規則

2026-08-05 の補充対応として、ページ見出しと管理区画見出しの先頭に業務内容を示す機能アイコンを配置する。

1. 顧客情報及び個人タスクのページ見出しは `portal-page-hero-icon` を使用し、アイコンの表示領域を 62px 四方に統一する。
2. 基本台帳、システム管理、問合支援、ワークフォース管理、問合検索テンプレート及びモデル設計の管理区画は `portal-section-heading-icon` を使用し、アイコンの表示領域を 48px 四方に統一する。
3. アイコンは業務の意味に対応する Ant Design Icons を選択し、単なる装飾として同一アイコンを使い回さない。
4. アイコンの色、背景、枠線、角丸及び文字との間隔は共通 CSS で管理する。個別ページで同じ値を再定義しない。
5. 900px 以下では見出しの内容と操作領域を縦方向へ配置し、アイコンは見出し本文の上端にそろえる。
6. 640px 以下でもアイコン、見出し本文及び操作領域が親領域からはみ出さない。見出し本文には `min-width: 0` を適用する。

## 受入確認

1. 顧客情報、個人タスク、問合支援、基本台帳、システム管理及び占位機能の見出しに共通表現が適用されている。
2. 900px 以下で操作領域が縦方向へ移動し、640px 以下で横方向の溢れが発生しない。
3. Portal の単体試験、TypeScript ビルド、実行中ページの表示、ブラウザーコンソール及びスクリーンショットを確認する。
