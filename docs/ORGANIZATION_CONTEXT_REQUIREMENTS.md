# 組織機関コンテキスト要件

更新日: 2026-08-05

## 表示名称

業務画面上部の組織機関選択欄は「組織機関」と表示する。

旧称の「共通コンテキスト」は使用しない。

## 検索対象

組織機関選択欄は、次の業務項目を検索対象とする。

1. 機関 Code
2. 機関名
3. 略称

検索文字列は NFKC 正規化と大文字小文字を区別しない比較を適用する。

選択候補と選択後の表示には、機関 Code と正式な機関名を `Code Name` の順序で同時に表示する。略称は検索対象として使用し、表示値には使用しない。

## 適用範囲

組織機関コンテキストを必要とする業務機能に表示する。

基本台帳とシステム管理では表示しない。
