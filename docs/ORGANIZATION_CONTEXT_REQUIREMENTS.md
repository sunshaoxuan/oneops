# 組織機関コンテキスト要件

更新日: 2026-08-10

## 表示名称

業務画面上部の組織機関選択欄は「組織機関」と表示する。

旧称の「共通コンテキスト」は使用しない。

## 検索対象

組織機関選択欄は、次の業務項目を検索対象とする。

1. 機関 Code
2. 機関名
3. 略称

検索文字列は NFKC 正規化と大文字小文字を区別しない比較を適用する。

選択候補と選択後の表示には、機関 Code と正式な機関名を `Code Name` の順序で同時に表示する。略称は検索対象として使用し、表示値には使用しない。

## 表示順

組織機関選択欄の候補は、機関 Code の昇順で表示する。

数字を含む機関 Code は数値部分を自然順で比較し、同じ結果になる場合は現在の画面ロケールを使用して比較する。

## 適用範囲

組織機関コンテキストを必要とする業務機能に表示する。

基本台帳とシステム管理では表示しない。

## 選択状態の保持

組織機関の選択値は `organizations.id` の物理 ID で保持する。機関 Code と名称は検索及び表示に使用する。

同じ利用者と同じ権限構成で画面を移動する間は、利用者が明示的に選択した組織機関を保持する。Workbench から AIアシスタントへ移動し、システム管理の Model API 又は顧客情報 CAG 分析を経由して Workbench へ戻る場合も同じ物理 ID を使用する。

組織機関選択欄を表示しないシステム管理で取得した Dashboard Snapshot に選択中の組織機関が一時的に含まれない場合、その Snapshot によって利用者の選択を先頭組織へ変更しない。選択中の組織機関を含む直前の組織情報を同じ権限構成内で保持し、顧客情報 CAG 分析にも同じ物理 ID を渡す。

利用者が選択した時点の Dashboard Snapshot より古い Cache を画面復帰時に再表示した場合、その Cache によって選択中の組織機関を変更しない。選択時点と同等又は新しい Snapshot を組織機関の再検証に使用する。

組織機関コンテキストを使用する業務画面で新しい Dashboard Snapshot を取得した時は、選択中の物理 ID を再検証する。当該物理 ID が存在しない場合は有効な先頭組織へ変更する。権限構成が変わった場合は以前の権限構成で保持した組織機関を使用しない。
