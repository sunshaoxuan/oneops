# 利用者編集画面識別要件

更新日: 2026-08-05

## 目的

ユーザー管理の編集 Modal を開いた際に、管理者が編集対象の利用者を即時かつ継続的に識別できるようにする。

## 表示要件

1. Modal のタイトルへ編集対象の表示名を表示する。
2. Modal 本文の先頭へ編集対象を示す専用領域を設ける。
3. 専用領域では表示名とユーザー名を常に表示する。
4. メールが登録されている場合はメールを表示する。
5. Windows Identity が登録されている場合はドメインアカウントを表示する。
6. 日本語、簡体字中国語及び英語で「編集中のユーザー」に相当する見出しを表示する。
7. 680px 以下の表示幅では識別情報を縦配置とし、横方向の欠落を発生させない。

## データ及び操作要件

識別情報は編集中の `ManagedUser` から参照し、入力項目として扱わない。保存 Payload には識別表示のための追加値を含めず、既存の状態、ロール、社内部門及び業務職責の更新契約を維持する。

## 受入条件

1. 編集 Button を選択した行と Modal の表示名、ユーザー名が一致する。
2. 同名利用者をユーザー名、メール又はドメインアカウントで区別できる。
3. Modal のタイトルと本文先頭の両方で編集対象を確認できる。
4. 保存、キャンセル及び閉じる操作で既存挙動を維持する。
5. Desktop と狭幅表示で文字切れ及び意図しない横 Scroll がない。
6. Console Error と Warning が 0 件である。
7. 正式環境で Screenshot を取得し、当初目的と逐項照合する。

## 最終受入

利用者状態ローカライズの最終受入と統合し、当初目的、表示要件、データ及び操作要件、受入条件を先頭から逐項確認する。不合格項目を修正した場合は統合した最終受入全体を先頭から再実行する。
