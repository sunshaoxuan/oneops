# 問合支援 AI 分析評価 要求仕様

## 目的

問合支援で生成された AI 分析に対する利用者評価を収集し、分析実行の入力、出力、利用モデル及び実行履歴と結び付けて、将来の教師あり学習及び品質評価に利用できる資料として保存する。

## 機能要求

1. 完了した AI 分析には「参考になった」と「改善が必要」の二種類の評価操作を表示する。
2. 「参考になった」は選択時に保存する。
3. 「改善が必要」は理由、提案又は評価を 2000 文字以内で入力できる。コメントを空欄のまま保存することもできる。
4. 同一利用者が同一 AI 分析へ登録できる現行評価は一件とし、再操作時は既存評価を更新する。
5. 評価は AI 分析実行の物理 ID と評価者の物理 ID を外部キーで保持する。
6. 評価者 ID は認証済み利用者情報から決定し、画面入力値を受け付けない。
7. 未完了、失敗又は論理削除済みの AI 分析は評価対象外とする。
8. AI 分析履歴取得時は、現在利用者自身の評価だけを返す。
9. 評価登録及び更新は操作監査へ記録する。

## データ契約

`inquiry_assist_run_evaluations` は評価 ID、AI 分析実行 ID、評価者利用者 ID、評価値、自由記述、作成日時及び更新日時を保存する。評価値は `POSITIVE` と `NEGATIVE` に限定する。分析実行と評価者の組合せを一意とする。

## 教師あり学習利用境界

評価単体を正解データとして扱わず、対応する分析入力、分析出力、モデル情報及び実行時点と結合したレビュー候補として使用する。自由記述には業務情報が含まれる可能性があるため、学習用抽出、匿名化、承認及び外部提供は本機能の範囲外とし、別途管理手順を要求する。
