# 用户与权限管理界面要求

## 1. 标题区操作位置

1. 基本台账位于系统管理上方，两者是左侧同级入口。系统管理的身份功能从页面顶部“用户管理”子菜单进入，用户、角色权限和认证审计作为下拉功能项。
2. 身份功能内容区使用系统管理卡片的完整宽度，不设置固定左侧二级导航。
3. 用户管理、角色与权限、认证审计等同级页面使用统一标题区。
4. 标题图标、页面名称和说明位于标题区左侧。
5. 页面级新增操作位于标题区右侧，与标题内容垂直居中。
6. 表格卡片从标题区下一行开始，页面级新增按钮不得占用表格内容区。
7. 窄屏下标题内容和新增操作改为纵向排列，新增按钮使用可点击的整行宽度。

## 2. 角色与权限

1. “添加角色”属于页面级操作。
2. 日文“ロールを追加”、中文“添加角色”和英文“Add role”使用同一位置和布局。
3. 只读用户不显示新增按钮，标题区间距保持不变。

## 3. ロール権限編集ダイアログ

1. ダイアログ全体の高さはブラウザーの表示領域から上下 16px の余白を引いた範囲内に収める。
2. タイトル、ロール基本情報、保存操作は常にダイアログ内の可視領域に残す。
3. 権限マトリクスは表示領域に応じた高さを持つ内部スクロール領域とし、行数が増えてもダイアログ全体を縦方向へ拡張しない。
4. 権限マトリクスの横方向スクロールは維持し、機能ノード列と操作列の固定幅を崩さない。

## 4. 验收

1. 角色与权限页面的新增按钮与基本台账中的组织机关、组织区分、产品与版本页面保持一致。
2. 表格外框顶部不再出现悬空按钮。
3. 桌面宽度和窄屏宽度均无按钮遮挡或溢出。
4. 生产构建、实际页面、浏览器控制台和截图验证通过。

身份管理标题区、表格卡片和操作区间距遵循
